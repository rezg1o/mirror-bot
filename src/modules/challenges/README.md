# Challenges Module

Owns one-to-one and group invitations to a curated experiment.

Responsibilities:
- Create, close, and expire challenges.
- Generate and validate shareable invitation links.
- Enforce participant limits.
- Join a participant once and resume existing membership.
- Connect challenge membership to the user's existing experiment participation.

Participants complete challenges in private bot chats. A group challenge does not require adding MIRROR to a Telegram group. Individual answers remain private.
